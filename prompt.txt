

Build a complete beginner-friendly portfolio project called AI Writing Improvement Lab.

Goal

Create an application that demonstrates how AI responses can be improved using human feedback.

The system should generate multiple rewrites of a piece of text, allow humans to evaluate and rank those rewrites, store preference data, analyze what characteristics people prefer, and compare an original generation strategy against an improved generation strategy.

The project should demonstrate:

* supervised fine-tuning concepts
* demonstrations
* human preference data
* RLHF concepts
* response evaluation
* reward signals
* reward-model concepts
* constraint following
* iterative improvement
* reward hacking
* evaluation on unseen examples

Do not implement large-scale PPO or real production RLHF.

Instead, create an educational simulation of the workflow that is understandable and portfolio-ready.

Core Workflow

The app should allow the user to enter:

1. Original text
2. Rewrite instruction
3. Optional constraints

Example:

Original:
“I need your answer today.”

Instruction:
“Make this more polite.”

Constraint:
“Do not change the deadline.”

The app generates three candidate rewrites.

For example:

Response A:
“Could you please provide your answer by the end of today?”

Response B:
“I would really appreciate receiving your response whenever you have time.”

Response C:
“Please answer today.”

The evaluator then scores each response using a rubric.

The evaluator ranks the candidates from best to worst.

The evaluator explains why the best response is better.

Save that data.

Evaluation Rubric

Score every candidate from 1 to 5 for:

* Meaning Preservation
* Instruction Following
* Constraint Following
* Clarity
* Tone
* Conciseness
* Overall Quality

Provide descriptions.

Meaning Preservation:
Does the rewrite retain the important meaning of the original?

Instruction Following:
Does it perform the requested transformation?

Constraint Following:
Does it respect explicit restrictions?

Clarity:
Is it easy to understand?

Tone:
Does it have the requested tone?

Conciseness:
Is it appropriately concise?

Overall Quality:
How successful is the rewrite overall?

Improvement Experiment

This is an important part of the project.

Create two generation strategies:

Baseline Strategy

and

Improved Strategy

Baseline Strategy:
Give the model only the original rewrite request.

Improved Strategy:
Use a stronger system prompt emphasizing:

* preserve original meaning
* satisfy every explicit constraint
* use requested tone
* avoid adding unsupported information
* prioritize instruction following over unnecessary stylistic changes
* verify the final answer against the user’s constraints before returning it

Allow the user to run both strategies on the same new task.

Generate:

Baseline Response

Improved Response

Display both side by side.

Ask the evaluator which is better.

Save these comparison results separately.

The purpose is to demonstrate:

Evaluate
→ identify weakness
→ make targeted change
→ evaluate again.
